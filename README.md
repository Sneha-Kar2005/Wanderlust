WanderLust is a full-stack web application inspired by Airbnb, designed to provide users with a seamless platform for discovering, exploring, and managing property listings.

The project is built using Node.js, Express.js, MongoDB, and EJS, with features such as user authentication, listing creation and management, reviews, interactive maps, and image uploads.

It demonstrates the development of a complete web application, combining a responsive user interface with backend functionality and database integration.

Features
User registration and authentication
Create, edit, and delete property listings
Browse and search destinations
Add and manage reviews
Interactive maps for property locations
Image uploads and cloud storage
Secure session management
Technologies Used
HTML, CSS, JavaScript
Node.js and Express.js
MongoDB and Mongoose
EJS and EJS-Mate
Passport.js
Mapbox
Cloudinary

This project was developed to strengthen my full-stack web development skills and gain practical experience building a real-world application.
